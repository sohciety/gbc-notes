# COMP1238 - Introduction to Data Management

## Week 1 - History and Representation of Information

- Computers represent information using binary, a base-2 number system that uses only the digits 0 and 1. Bits can be combined to represent numbers, text, and other types of information.
- A bit is one binary digit, while a byte contains 8 bits. Different combinations of bits can represent different values.
- Early computing systems used punched cards to store and process information. Holes in specific positions represented data or instructions.
- Text requires character encoding so computers can represent letters, numbers, punctuation, and symbols. Unicode provides a standard for representing characters from many writing systems.
- UTF-8 is a widely used character encoding that represents Unicode characters using one to four bytes.
- The @ symbol is an example of a character whose use has changed over time, including its use in email addresses.

## Week 2 - Text Files and Markup Languages

- Plain-text files contain characters without requiring special formatting instructions. Whitespace, punctuation, and line breaks can affect how text is interpreted.
- Markdown is a lightweight markup language that uses simple characters to format text. For example, # creates a heading, **text** creates bold text, and - creates a bullet list.
- Markdown can create headings, links, images, lists, checkboxes, and code blocks. A Markdown file usually uses the .md extension.
- HTML uses elements and tags to describe the structure of a web page. For example, <h1> creates a main heading and <p> creates a paragraph.
- Raw Markdown is the source text containing formatting symbols, while rendered Markdown is the formatted result displayed to the reader.
- Special characters sometimes need escaping so they are displayed literally instead of being interpreted as formatting. Code blocks can preserve text such as ASCII art and programming examples.
- File extensions, such as .txt, .md, and .html, help identify the type and intended use of a file.

## Week 3 - Structured Data, JSON, and XML

- Structured data follows a consistent organization, making it easier for computers to store, process, search, and exchange information.
- JSON stands for JavaScript Object Notation. It is a text-based format commonly used to represent and exchange structured data.
- JSON objects contain key-value pairs enclosed in curly braces. For example, {"name": "Alex", "age": 19} contains two properties.
- JSON supports strings, numbers, booleans, null values, objects, and arrays. Arrays use square brackets and can contain multiple values.
- JSON syntax requires double quotes around property names and string values. Commas separate items, and colons separate keys from their values.
- XML stands for Extensible Markup Language. It represents information using nested opening and closing tags.
- Escaping is important when characters have special meanings in a data format. For example, JSON strings use escape sequences such as \\" for a quotation mark and \\\\ for a backslash.
- Structured data is different from unstructured text because it follows a defined format that software can interpret more consistently.

## Week 4 - Command-Line Tools and GitHub

- A command-line interface (CLI) allows users to interact with a computer by entering text commands instead of relying entirely on a graphical interface.
- Common command-line operations include navigating directories, listing files, creating folders, and creating or editing files.
- Git is a version-control system that tracks changes to files over time. It allows users to review earlier versions and understand how a project changed.
- GitHub is an online platform for hosting Git repositories and collaborating on projects. A repository contains project files and their history.
- A commit records a set of changes to a repository. A useful commit message briefly explains what was changed.
- A README.md file explains a repository and can include headings, links, lists, images, and code examples using Markdown.
- GitHub's web interface allows users to edit files, preview Markdown, and commit changes without using the command line.
- GitHub Actions can run automated workflows, such as checking an assignment or building a website. The Actions tab displays workflow results and logs.
- GitHub Pages can publish a website from a repository. A successful build and deployment are needed for the published website to be available.

## Week 5 - Data Management, Airtable, and Databases

- Data management involves organizing, storing, maintaining, and retrieving information so it can be used reliably.
- Spreadsheets and database tools can both organize information in rows and columns, but databases provide additional ways to define relationships, query data, and manage larger collections of records.
- Airtable combines spreadsheet-style tables with database features. Tables contain records (rows) and fields (columns).
- A relational database stores information in related tables. Each table represents a particular subject or entity, such as students, courses, or orders.
- A primary key uniquely identifies each record in a table. A foreign key references a key in another table to establish a relationship.
- Entity-relationship diagrams (ERDs) visually represent entities, their attributes, and the relationships between them.
- SQL stands for Structured Query Language. It is used to create, retrieve, update, and delete data in relational databases.
- SELECT retrieves data, INSERT adds records, UPDATE modifies existing records, and DELETE removes records.
- The WHERE clause filters records based on a condition. ORDER BY sorts query results, while GROUP BY groups records for aggregate calculations.
- Database transactions help ensure that a group of related operations is handled reliably. ACID refers to atomicity, consistency, isolation, and durability.
